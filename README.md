# Юрекс — сайт юридической помощи в трудовых спорах

Одностраничный адаптивный сайт (лендинг) для привлечения клиентов, которым требуется юридическая помощь в сфере трудового права: невыплата зарплаты, незаконное увольнение, споры с работодателем и т.д.

Сайт сделан на чистом HTML/CSS/JS — без сборщиков и фреймворков. Его можно открыть прямо в браузере или залить на любой хостинг (Netlify, Vercel, GitHub Pages, обычный хостинг по FTP).

## Структура проекта

```
index.html                       — вся разметка и содержимое сайта
css/styles.css                    — стили (приглушённая каменная цветовая схема)
css/legal.css                     — стили юридических страниц и cookie-баннера
js/main.js                        — меню, анимации, счётчики, обработка формы, cookie-баннер
assets/favicon.svg                — иконка сайта
backend/google-apps-script/       — приём заявок: Google-таблица + Telegram (см. ниже)
legal/                             — документы по персональным данным и другим законам РФ (см. legal/README.md)
```

## Юридические документы (персональные данные и не только)

В папке [`legal/`](./legal/README.md) собран комплект документов, обязательных для сайта, который собирает персональные данные клиентов на территории РФ: политика обработки персональных данных, пользовательское соглашение, информация об исполнителе услуг (публикуются на сайте — ссылки уже стоят в футере и в форме заявки), а также внутренние документы (приказ о назначении ответственного, положение об обработке ПДн, реестр обработки данных в виде таблицы, инструкция по уведомлению Роскомнадзора, план реагирования на утечки, шаблон договора с клиентом).

**Обязательно откройте [`legal/README.md`](./legal/README.md)** — там чек-лист внедрения и важные замечания про текущую схему хранения заявок в Google Таблице (трансграничная передача данных требует отдельного согласия и, скорее всего, уведомления Роскомнадзора).

## Что нужно поменять перед публикацией

1. **Название компании** — сейчас используется название «Юрекс». Если понадобится сменить — заменяется во всех местах `index.html` (логотип, футер, title, meta description) через поиск-замену.
2. **Контакты** — замените телефон `+7 (999) 999-99-99` и почту `info@yureks.ru` на реальные (встречаются в шапке, блоке «Контакты» и футере).
3. **Адрес** — в футере указан плейсхолдер «г. Москва (укажите свой адрес)».
4. **Соцсети** — ссылки Telegram/WhatsApp/VK в футере сейчас ведут на `#`, вставьте реальные ссылки.
5. **Цифры в блоке статистики** (лет практики, выигранных дел, взысканная сумма, % успешных дел) — сейчас это примерные значения для демонстрации. Замените на реальные показатели вашей практики в `data-count` атрибутах в `index.html` (секция `.stats`).
6. **Отзывы** — три отзыва в разделе «Отзывы» являются примерами. Замените их текстом и именами реальных клиентов (по возможности — с согласия клиентов, без лишних персональных данных).
7. **Юридические документы** — политика обработки персональных данных, пользовательское соглашение и информация об исполнителе уже добавлены в папку `legal/` и подключены (футер, форма заявки, cookie-баннер). Перед публикацией нужно заполнить в них реальные реквизиты вместо `[плейсхолдеров]` — подробности и чек-лист в [`legal/README.md`](./legal/README.md).

## Подключение формы заявок

Форма на странице полностью рабочая (валидация, защита от спам-ботов через honeypot-поле). Заявки обрабатываются по схеме **Telegram + Google-таблица**:

- Каждая заявка мгновенно приходит уведомлением в Telegram-чат, чтобы вы сразу узнавали о новом клиенте.
- Параллельно заявка записывается строкой в общую Google-таблицу с колонками «Статус» (Новая / В работе / Консультация проведена / Закрыта / Отказ) и «Ответственный» — так вы с партнёром ведёте общий реестр обращений и видите, кто чем занимается.

Всё это работает через один бесплатный Google Apps Script, без отдельного хостинга — привязан к обычному Google-аккаунту.

**Пошаговая настройка (10–15 минут)** — полностью расписана в [`backend/google-apps-script/README.md`](./backend/google-apps-script/README.md). Коротко порядок действий:

1. Создать Telegram-бота и общий чат с партнёром.
2. Создать Google-таблицу и вставить в неё код из [`backend/google-apps-script/Code.gs`](./backend/google-apps-script/Code.gs).
3. Один раз запустить функцию `setupSheet` — таблица подготовится автоматически (заголовки, выпадающие списки статусов и ответственных).
4. Опубликовать скрипт как веб-приложение и получить его URL.
5. Вставить этот URL в файл `js/main.js` в переменную `LEADS_WEBHOOK_URL`.

Пока `LEADS_WEBHOOK_URL` не заполнен, форма работает в демо-режиме — заявки просто выводятся в консоль браузера, чтобы можно было тестировать сайт до подключения бэкенда.

### Альтернативы (если понадобится другой способ)

- **Только email через [Formspree](https://formspree.io)** — проще всего, но без общего реестра и статусов заявок.
- **Полноценная CRM (amoCRM, Bitrix24)** — стоит рассмотреть при заметном росте потока заявок, когда нужна воронка продаж, задачи и напоминания.

## Как посмотреть сайт локально

Просто откройте `index.html` в браузере двойным кликом, либо запустите локальный сервер, например через:

```
npx serve .
```

или через встроенный сервер Python:

```
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Дальнейшее развитие

Сайт спроектирован так, чтобы его можно было легко расширить под другие направления юридических услуг (не только трудовое право) — достаточно добавить новые карточки в секцию «Услуги» или создать отдельные страницы/разделы по другим отраслям права.
