# Приём заявок: Telegram + Google-таблица

Эта папка содержит серверную часть для обработки заявок с формы на сайте. Отдельный хостинг не нужен — всё работает через бесплатный Google Apps Script, привязанный к обычному Google-аккаунту.

**Как это работает:**

1. Посетитель отправляет форму на сайте.
2. Сайт делает запрос в веб-приложение Google Apps Script.
3. Скрипт дописывает заявку новой строкой в Google-таблицу (с колонками «Статус» и «Ответственный»).
4. Скрипт сразу же отправляет уведомление о новой заявке в ваш Telegram-чат с партнёром.

Ниже — пошаговая настройка. Займёт 10–15 минут, делается один раз.

## Шаг 1. Создайте Telegram-бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Придумайте имя и username для бота (например, `yureks_leads_bot`).
3. BotFather пришлёт **токен бота** — строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Сохраните её, она понадобится ниже.

## Шаг 2. Узнайте chat_id вашего чата с партнёром

Проще всего — через общий чат/группу, куда добавлены вы, партнёр и бот:

1. Создайте в Telegram группу (например, «Юрекс — заявки») и добавьте туда себя, партнёра и созданного бота.
2. Напишите в группе любое сообщение.
3. В браузере откройте адрес (подставив свой токен):
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. В ответе (это JSON) найдите поле `"chat":{"id": -1001234567890, ...}` — это и есть нужный вам `chat_id` (для групп он обычно отрицательный, это нормально).

Если вместо группы хотите получать заявки в личные сообщения от бота — просто напишите боту `/start` и возьмите `chat_id` из того же `getUpdates`-ответа (там он будет положительным).

## Шаг 3. Создайте Google-таблицу

1. Откройте [Google Sheets](https://sheets.google.com) и создайте новую пустую таблицу.
2. Назовите её, например, «Юрекс — заявки с сайта».

## Шаг 4. Добавьте код Apps Script

1. В таблице откройте меню **Расширения → Apps Script**.
2. Удалите содержимое файла `Code.gs`, которое там по умолчанию, и вставьте вместо него весь код из файла [`Code.gs`](./Code.gs) из этой папки.
3. В самом начале файла заполните настройки:
   ```
   const TELEGRAM_BOT_TOKEN = 'ВАШ_ТОКЕН_БОТА';
   const TELEGRAM_CHAT_ID = 'ВАШ_CHAT_ID';
   ```
   Подставьте значения, полученные в шагах 1–2.
4. При желании поправьте список `ASSIGNEE_OPTIONS` — впишите туда реальные имена вас и партнёра (это будет выпадающий список в колонке «Ответственный»).
5. Сохраните проект (значок дискеты или Ctrl/Cmd+S). Название проекта можно изменить, например, на «Юрекс — приём заявок».

## Шаг 5. Инициализируйте таблицу

1. В редакторе Apps Script в выпадающем списке функций (рядом с кнопкой «Выполнить») выберите `setupSheet`.
2. Нажмите **Выполнить**. При первом запуске Google попросит выдать скрипту разрешения — согласитесь (это ваш собственный скрипт в вашем аккаунте, доступ безопасен).
3. Проверьте таблицу — должен появиться лист «Заявки» с заголовками и подготовленными колонками «Статус» и «Ответственный» с выпадающими списками.

## Шаг 6. Проверьте Telegram-уведомление (необязательно, но рекомендуется)

1. В списке функций выберите `testTelegramNotification` и нажмите **Выполнить**.
2. В Telegram-чат должно прийти тестовое сообщение с примером заявки. Если сообщение не пришло — проверьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Шаг 7. Опубликуйте веб-приложение

1. В редакторе Apps Script нажмите **Развернуть → Новое развёртывание** (Deploy → New deployment).
2. Тип развёртывания — **Веб-приложение** (Web app).
3. Настройки:
   - **Выполнять как (Execute as):** я (ваш аккаунт).
   - **У кого есть доступ (Who has access):** Все (Anyone) — это обязательно, иначе сайт не сможет отправлять данные.
4. Нажмите **Развернуть** и разрешите доступ, если Google снова спросит.
5. Скопируйте выданный **URL веб-приложения** — он выглядит как `https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXX/exec`.

## Шаг 8. Подключите URL к сайту

1. Откройте файл `js/main.js` в корне проекта сайта.
2. Найдите строку:
   ```js
   const LEADS_WEBHOOK_URL = '';
   ```
3. Вставьте туда скопированный URL:
   ```js
   const LEADS_WEBHOOK_URL = 'https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXX/exec';
   ```
4. Сохраните файл и опубликуйте сайт.

Готово — теперь при отправке формы на сайте заявка будет одновременно попадать в Google-таблицу и присылаться уведомлением в Telegram.

## Как пользоваться таблицей вдвоём с партнёром

- Откройте доступ к таблице партнёру (кнопка «Настройки доступа» / Share в Google Sheets) — оба сможете видеть и редактировать заявки.
- Колонка **«Статус»** — кликните на ячейку, появится выпадающий список: `Новая`, `В работе`, `Консультация проведена`, `Закрыта`, `Отказ`.
- Колонка **«Ответственный»** — так же выпадающий список с именами партнёров. Тот, кто берёт заявку в работу, проставляет здесь своё имя.
- Колонка **«Заметки»** — свободное поле для деталей по клиенту, истории звонков и т.д.
- Можно включить фильтр (Данные → Создать фильтр), чтобы быстро смотреть только «Новые» заявки или заявки конкретного партнёра.

## Если что-то не работает

- **Заявка не появляется в таблице и Telegram** — откройте в Apps Script вкладку «Выполнения» (Executions) слева, там видно, были ли ошибки при последнем вызове `doPost`.
- **В Telegram ничего не приходит, а в таблицу пишет** — скорее всего неверный `TELEGRAM_BOT_TOKEN` или `TELEGRAM_CHAT_ID`. Перепроверьте шаги 1–2 и запустите `testTelegramNotification` ещё раз.
- **После правок кода ничего не изменилось** — Apps Script публикует именно то развёртывание, которое было создано в шаге 7. После изменения `Code.gs` нужно сделать **Развернуть → Управление развёртываниями → значок редактирования → Новая версия → Развернуть**, иначе сайт продолжит обращаться к старой версии скрипта.

## Альтернативы (если этот способ не подойдёт)

- **Только email через [Formspree](https://formspree.io)** — проще в настройке, но заявки не будут структурированы в таблице. Если понадобится, могу подключить вместо (или вместе с) описанным выше способом.
- **Полноценная CRM (amoCRM, Bitrix24)** — стоит рассмотреть, когда поток заявок вырастет и понадобится воронка продаж, задачи и напоминания.
